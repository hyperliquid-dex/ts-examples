# ts-examples

Sample scripts/snippets for computing various frontend values. Refer to [@nktas/hyperliquid](https://github.com/nktkas/hyperliquid), [hyperliquid-ts-sdk](https://github.com/nomeida/hyperliquid) or the [Hyperliquid JavaScript SDK (@siebly/hyperliquid-api)](https://siebly.io/sdk/hyperliquid/javascript) for Typescript SDKs written by members of the community.

You can run OrderExample by installing the dependencies `npm install` and then using tsx `npm tsx examples/OrderExample.tsx`
